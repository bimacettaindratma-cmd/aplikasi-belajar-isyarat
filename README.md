# 🤟 IsyaratKu - Aplikasi Belajar Isyarat BISINDO

**IsyaratKu** adalah platform web interaktif berbasis Next.js yang dirancang untuk membantu masyarakat mempelajari Bahasa Isyarat Indonesia (BISINDO) dengan mudah, terstruktur, dan menyenangkan.

---

## ✨ Fitur Utama
* **🔤 Kamus Alfabet & Angka**: Panduan interaktif peragaan isyarat huruf A–Z dan angka 0–10 lengkap dengan demonstrasi visual.
* **🃏 Mode Flashcard**: Fitur hafalan taktis untuk mempercepat ingatan jangka pendek pengguna terhadap gerakan tangan.
* **▶️ Kompilasi Video Utama**: Halaman streaming video panduan menyeluruh yang dilengkapi dengan fitur *timestamp* (akses cepat per babak) serta tips ekspresi mimik wajah.
* **🤖 Deteksi Kamera Real-Time (AI)** *(Sedang Dikembangkan)*: Fitur pemanfaatan webcam menggunakan TensorFlow.js dan Google MediaPipe untuk memvalidasi akurasi gerakan tangan pengguna secara langsung.

---

## 🛠️ Teknologi yang Digunakan
* **Framework Utama**: Next.js 14+ (App Router)
* **Bahasa Pemrograman**: TypeScript
* **Styling & Desain**: Tailwind CSS
* **Ikon**: `@tabler/icons-react`
* **Kecerdasan Buatan (AI)**: `@tensorflow/models/handpose` & Google Teachable Machine
